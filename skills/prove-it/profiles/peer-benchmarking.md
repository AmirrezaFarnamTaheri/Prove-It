# Profile: Peer Benchmarking & External Research

Activate when current external practices, standards, or peer implementations can materially improve a decision.

<benchmarking_profile>
Prefer authoritative primary sources and mature comparable systems. Search for historical failure modes, security/scaling pitfalls, mitigation patterns, standard capabilities, and mechanisms worth adapting.

Do not cargo-cult. For each significant external pattern ask:
1. What exact problem does it solve?
2. Does this target actually have that problem?
3. What mechanism is transferable?
4. What context-specific parts should not be copied?
5. What benefit is expected?
6. What complexity/risk is introduced?
7. How will success be validated?

Classify opportunities separately from defect severity as Incremental, High-Leverage, or Transformational.
</benchmarking_profile>
