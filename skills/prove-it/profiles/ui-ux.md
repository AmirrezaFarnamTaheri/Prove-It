# Profile: UI / UX & Accessibility

Activate for user-facing or developer-facing graphical interfaces.

<ui_profile>
Verify:
- information and visual hierarchy;
- task/interaction flow;
- terminology and consistency;
- validation feedback and error states;
- loading and empty states;
- responsive behavior;
- keyboard access and visible focus;
- semantic labels and contrast;
- reduced-motion behavior where relevant;
- localization/format assumptions.

Use a coherent design system when the product warrants one. Do not force an aesthetic trend unrelated to the product.

Optimize for legibility, hierarchy, usability, accessibility, consistency, and perceived performance. Use optimistic UI only when failure/reconciliation behavior is safe and explicit.
</ui_profile>
